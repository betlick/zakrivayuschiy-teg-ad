# Закрывающий тег

Учебный проект по вёрстке: восемь карточек о пройденном пути, адаптивный интерфейс, CSS-фильтры, анимированные лайки и модальное окно.

## Запуск

Откройте папку в VS Code и запустите `index.html` через Live Server. Либо выполните в папке проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Дополнительные зависимости и сборка не нужны. Сервер нужен для загрузки внешнего SVG-символа дискеты.

## Реализация

- HTML: семантические карточки, заголовки, кнопки и нативный `dialog`.
- Все CSS-переменные находятся в `styles/variables.css`.
- Локальные шрифты Inter Variable (400–785) и PressStart2P.
- Фиксированный фон из трёх градиентов и резиновая ширина блоков.
- Восемь фотографий, добавленных автором проекта, с разными CSS-фильтрами. У экспортированных изображений уже есть эффекты, поэтому дополнительные фильтры сделаны мягкими.
- SVG-символ дискеты используется через `use`.
- Сердце разделено на `core`, `main-body`, `contour`, `sparks` и группу `heart`.
- Лайк работает по обеим кнопкам; состояние передаётся через `aria-pressed`.
- Поддерживаются клавиатура и системная настройка уменьшения анимаций.
- SVG-фавикон, ICO (16/32 px), PNG для iOS (180 px).

## Перед сдачей

Вторые абзацы карточек — примеры личных воспоминаний, а не подтверждённые сведения об авторе. При желании замените их на свои: места отмечены комментариями в HTML.

[Макет Figma](https://www.figma.com/design/Yg5IFeWSyl6Js98kWROjVP/?node-id=25-1654). Автоматический доступ к параметрам макета закрыт, поэтому точное совпадение с ним пока не подтверждено. Использованы изображения, фавикон и дискета, экспортированные автором проекта.

## Публикация

Отправьте изменения в свой GitHub-репозиторий. В **Settings → Pages** выберите **Deploy from a branch**, нужную ветку и папку **/(root)**. После публикации добавьте фактическую ссылку сюда.

| Элемент | Макет | После исправления |
| --- | --- | --- |
| Шапка, desktop | 700 × 368 px | 700 × 368 px (с округлением до пикселя) |
| Шапка, mobile | 375 × 327 px | 375 × 327 px |
| Диалог, desktop | 353 × 191 px | 353 × 191 px |
| Диалог, mobile | 341 × 191 px | 341 × 191 px |

Полная сверка карточек и анимаций пока не завершена: открытая Figma сообщает о потере соединения, переключение слоёв работает нестабильно.
